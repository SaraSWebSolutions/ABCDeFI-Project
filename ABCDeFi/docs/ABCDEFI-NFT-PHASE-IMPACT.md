# ABCDeFi NFT Phase Impact

## Phase 3 — Loan NFTs

No LoanNFTV2 contract, issuance, valuation provenance, API, or completion lifecycle is changed. Franchise certificates are distinct and have no LoanNFTV2 financial or completion role.

## Phase 8 — Legion

LegionNFTV2 remains canonical with its Country → State → District hierarchy and controlled transfers. This impact adds only the owner-approved ability for a separate Franchise Registry to reference an existing Legion token. It does not change Legion economics or direct-transfer restrictions.

## Phase 9 — Franchise

Phase 9 gains the canonical Legion-bound V2 implementation. Historical standalone foundation and lock evidence are preserved as historical records; they are not used as V2 canonical API truth.

## Phase 10A — ABCD NFT Marketplace

No Phase 10A behavior, economics, listing mechanism, or deployment changes. V2 Franchise NFTs prohibit ERC-721 approvals and therefore cannot be generically listed. This is an explicit boundary, not a new marketplace feature.

## Phase 10B — Legion Marketplace Settlement

No Phase 10B behavior changes. Its targeted Legion settlement role remains isolated. It does not settle or list FranchiseNFTV2.

## Phase 11 — Treasury

No Treasury contract, accounting, routing, funding, reward, or withdrawal behavior changes. Franchise V2 has no Treasury right or dependency.
